# AlienLearn · 一页纸

**一款 LLM-Agent 驱动的沉浸式外语语境沙盒。** 玩家扮演潜伏地球的外星人，接入一家雨夜拉面馆，
用目标语言点面、套出老板不写在菜单上的高汤配方。说错话不弹红叉 —— **世界会开始裂开。**

## 问题与洞察

语言学习的真问题不是内容不够，是**不敢开口**。
而弹窗式纠错让人越纠越沉默 —— 每个红色提示都在提醒你"你在考试"。

洞察：**把纠错从"评判"改成"世界的反馈"。** 老板绝不解释语法，只是皱眉、反问、
按自己的理解上菜；精确诊断静默滑进侧边栏，玩家可以不看。

## 核心机制：色差分离

视口把场景渲染成红、青两个通道再叠加。伪装稳时两层重合、画面清晰；
暴露度升高，两层沿 X 轴分离。**视觉惩罚不是特效，它就是渲染管线本身。**

## 架构与三个刻意的取舍

`Router →（Pedagogy ∥ Persona）→ 纯 Python 状态机`

- **没上 LangGraph**：三个节点上编排框架是过度设计。我要的是控制权 —— Router 必须先行，
  Pedagogy 与 Persona 必须并行（实测首字 1.43s，串行要多等一整个 JSON）
- **数值一律不给 LLM 碰**：伪装度、能量、阶段全在 Python，LLM 只发信号。
  防幻觉，也防玩家用 prompt 注入改血条
- **词数由代码算**：指标口径一旦被幻觉污染，后面基于它的判断都不可信。
  越狱也是英文，但不是学习行为，不计入北极星

## 四轮迭代（每轮都有留档报告）

| | 对局链路 | Router 拦截率 | Pedagogy 诊断准确率 |
| --- | --- | --- | --- |
| 一 | 规则桩 | 83.3% —— 低于我自己在 PRD 里写下的 90% 判据 | — |
| 二 | 规则桩 | 100% | 100%（不可信，见下） |
| 三 | DeepSeek | 100% | **73.3%** |
| 四 | DeepSeek | 100% | dev 集 100% / **留出集 60-70%** |

**第四轮是我最想讲的一轮。** 看到 73.3% 我的第一反应是"模型不行"，翻完原始 trace 后结论是反的：
模型每条诊断都对（`I is`→`I am`、`want eat`→`want to eat`，span 与改法无一处错），
它只是把档位判成 minor —— 而按我 prompt 里亲手写下的 `major = 影响理解`，**它是对的**。
是我的标注偷偷换了另一把尺子。**这是标注一致性问题，不是模型能力问题。**

所以我改的是判据不是模型：严重度改量**「暴露度」**而非「可理解度」——
它该回答的是"母语者会觉得这人口音重，还是觉得这人不对劲"。
**30 条标注一条没动**，改标注凑分数是移动球门。

dev 集因此升到 100%，但它的句子被我写成了 prompt 的 few-shot 锚点，满分是保送的。
所以我另补了 10 条留出集：**它只拿到 60-70%，而我刻意没去刷它** ——
留出集一旦用来调 prompt 就作废。

写成区间是因为同配置重跑了一次，它从 70% 掉到 60%：**temperature=0 不等于确定性**，
10 条样本里一条就是 10 个百分点。所以下一步是换手段（档位判定挪进代码）并把样本扩到 50+
—— 目的不是覆盖面，是让数字稳到能做决策。

## 边界

**有意不做**：账号、支付、公网部署、UGC 编辑器、语音、微调。
它们在 PRD 里都有位置，但不验证那个核心假设 ——
**"把纠错藏进世界规则里，玩家会不会更愿意开口"**。

**最大的短板**：留存尚未验证 —— 靠新奇感驱动的机制会衰减，这点我拿不出数据。
所以报告里它写的是"待验证假设"，不是结论。
