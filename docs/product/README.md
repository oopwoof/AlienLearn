## 一、立项时定下、并且真的落地了的

- **北极星指标 = 自发目标语言输出率**（PRD v0.2 第 5.1 节）→ 实现为
  `telemetry.north_star()` 的 `avg_target_words_per_session`，并且加了防刷：
  越狱产生的英文不计入
- **假设一的判定标准："拦截率低于 90%，说明解耦带来的 Latency 成本不划算"** →
  直接编码为 `eval/report.py` 里的 `ROUTING_BAR = 0.90`。
  **第一轮真的跑出了 83.3%，我改的是产品，不是判据**
- **三层越狱防御**（软回弹 / 视觉 Glitch / 硬崩溃三次）→ 全部落地，
  参数在 `backend/config.py` 的 `Rules`
- **层级化打分**（人设一致性 / 教学遵循度 / 安全）→ 落地为 `eval/judge.py` 的三维
- **红蓝对抗三套件**（正常通关 / 极差语法 / 刻意越狱）→ 落地，
  后来又加了第四个 `boundary` 泛化集
- **成本控制第二条"状态机剥离 LLM"** → 落地，且强化成了"数值一律不给 LLM 碰"
- **合规方案 A（全息碎片 + 地名异化）** → 落地，场景叫"新京都"而不是东京
- **魔法时刻**（PRD v0.2 第 1.2 节：量词用错 → 不弹红色错号，而是环境异变 +
  老板立绘红蓝错位 + 侧边栏像情报解密一样静默滑出纠错）→ **几乎是逐字实现的**，
  这一段是整个产品的设计原点

## 二、立项时写了、但被实现推翻的四处 ★

这四处是我认为这份文档集最有价值的部分 —— 立项时的判断留在纸上，
所以改了什么、为什么改，都可以被追溯。

**1. LangGraph → asyncio 显式编排**
PRD v0.1 和 v0.2 都明确写了"后端通过 LangGraph 将对话切分为离散节点"、
"采用 LangGraph 编排的专职 Agent 架构"。**实现里一行 LangGraph 都没有。**
理由：三个节点上编排框架是过度设计。而且我有两条硬约束 ——
Router 必须先行、Pedagogy 与 Persona 必须并行 —— 用 `asyncio` 显式写出来比藏在框架里清楚。
等节点数涨到需要条件分支和检查点再换框架，而不是反过来。

**2. Pedagogy「强制 NPC 复用目标句型」→ 诊断静默进 HUD，NPC 绝不当老师**
`Alienlearn.pdf` 里 Pedagogy Agent 的定义是"评估用户输入语法，
并**强制 NPC 在回复中复用**用户需要掌握的特定句型"。实现反过来了：
Persona 的第一条硬约束就是**绝不解释语法、绝不当老师**，精确诊断静默滑进侧边栏 HUD。
理由：让 NPC 复用目标句型，等于把老师塞回角色里 —— 而"弹窗式纠错让人闭嘴"
正是这个产品要消灭的东西。这是立项文档和产品内核自相矛盾的一处，我按内核改了。

**3. Tool-use 驱动状态机 → LLM 只投票，状态机自己决定**
PRD 写 NPC Agent 要具备调用 `update_quest_state(status="success")` 的能力来推动状态机。
实现改成：LLM 只输出 `quest_signal: advance|stay` 这个信号，
推进与否由 `backend/game_state.py` 里的 Python 决定，而且加了 `min_turns_per_stage` 闸门 ——
**LLM 说"可以推进"也得等。** 理由：把状态写权交给 LLM，等于让玩家能用 prompt 注入改自己的血条。

**4. 假设二的判据从「次日留存率」降级为「平均轮次」**（诚实降级）
PRD v0.2 写的是"触发纠错的玩家**次日留存率** vs 未触发的"。
但 MVP 没有账号体系，就没有"次日"。所以实现里降级成了同一 session 内的平均轮次对比，
并在报告第五节写明样本不足、结论待真实玩家数据。
**代理指标不如原判据，这一点我在报告里标出来，而不是悄悄换掉。**

## 三、写了但没做（有意的边界）

Retrieval / FAISS 向量库与白名单 RAG · SFT / DPO 两阶段训练管线与私有小模型 ·
面具抽卡 · 能量+广告 · 订阅制 · DLC 场景包 · 创作者经济 · UGC 编辑器 ·
公域大地图与全局变量握手协议 · 独立的合规审核 Agent · 大小模型分层路由

它们都不验证 MVP 要验证的那个假设 ——
**"把纠错藏进世界规则里，玩家会不会更愿意开口"**。
其中"独立的合规审核 Agent"值得单独说一句：现在的合规是靠 Router 的意图二分类
加 Persona 的硬约束做的，**没有单独的 Safety Agent**。
MVP 规模下够用，但 UGC 一旦开放，合规审核必须是独立的一层。
